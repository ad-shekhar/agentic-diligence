Quickstart: Running Your First Audit

Execute an end-to-end technical due diligence audit on benchmark target AcmeAI (Scenario A):

# 1. Start the live Agentic Diligence server
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 2. Run Scenario A benchmark and generate canonical diligence metrics
curl -X GET "http://127.0.0.1:8000/api/v1/scenarios/scenario_a/run?sample_size=100"

# 3. Or use the CLI to compute deterministic signals directly
python cli.py compute-metrics --scenario scenario_a --sample-size 100

# 4. Generate the Claim Verification Matrix
python cli.py claim-matrix --company <company_id>

Core REST API Endpoints

Method Endpoint Route Function & Purpose
POST /v1/traces OpenTelemetry GenAI OTLP HTTP/JSON trace ingestion gateway. Computes pre-parsing SHA-256 hash.
GET /api/v1/scenarios/{name}/run Generates reproducible synthetic ground-truth benchmark (scenario_a to scenario_j) and builds complete report.
GET /api/v1/companies/{id}/metrics Computes the 8 canonical diligence signals (AR, HIR, TCR, ER, TE, CPT, MC, TC) with confidence bounds.
GET /api/v1/companies/{id}/claim-matrix Evaluates company claims against observed bounds to produce formal Verified/Contradicted verdicts.
GET /api/v1/companies/{id}/aibom/cyclonedx Exports supply chain bill of materials in CycloneDX 1.6 / 1.5 JSON with OWASP schema validation.
GET /api/v1/companies/{id}/diligence-report Generates canonical diligence report package in JSON or Markdown format.
POST /api/v1/companies/{id}/bundle Compiles complete evidence bundle on disk with RFC 8785 canonical JSON manifest.json.
POST /api/v1/bundles/verify Cryptographically verifies an evidence bundle directory against its SHA-256 manifest.

CLI Command Reference

Agentic Diligence includes a full command-line suite in cli.py:

Command Options & Flags Description
python cli.py compute-metrics --scenario, --sample-size, --output-json Runs task segmentation and outputs all 8 diligence signals with trust attribution.
python cli.py claim-matrix --company <id>, --output <file> Generates and prints the formal Claim Verification Matrix.
python cli.py aibom --company <id>, --spec-version 1.6, --validate Exports CycloneDX AI-BOM and validates against official schema.
python cli.py bundle verify --dir <bundle_dir> Verifies cryptographic integrity and file completeness of a diligence bundle.
python cli.py compare-targets --target-a, --target-b, --sample-size Executes side-by-side head-to-head diligence comparison between two targets.
