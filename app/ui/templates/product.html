PRODUCT ARCHITECTURE

The Standardized Technical Diligence Operating System for AI

Agentic Diligence is built specifically for M&A corporate development teams, venture capital investors, and enterprise procurement leaders who need mathematically grounded certainty before deploying or acquiring autonomous AI agents.

1. Multi-Source Evidence Ingestion

Captures exact, immutable runtime traces directly from agent executions:

  • OpenTelemetry (OTel): GenAI Semantic Conventions v1.28.0 trace collector on standard HTTP endpoints.
  • Model Context Protocol (MCP): Intercepts tool declarations, client requests, and server responses.
  • Browser Agent Extension: Audits DOM action triggers, human confirmation dialogs, and navigation hops.
  • Pre-Parsing SHA-256 Hashing: Every raw byte payload is fingerprinted before parsing to guarantee non-repudiation.

2. Task Segmentation & Normalization

Solves the fundamental problem of agent runtime gap analysis:

  • Deterministic Task Boundaries: Clusters inter-connected spans into discrete atomic tasks.
  • Reaction Latency Heuristics: Separates programmatic sub-second tool hops from human delays (e.g. 15s+ operator pauses).
  • Uninstrumented Interval Handling: Gaps without telemetry are classified as [UNKNOWN] and widen statistical confidence bounds.
  • Honest Autonomy Rate: Pessimistic lower bound computation ensures unobserved executions are never counted as autonomous.

3. Deterministic Diligence Engine

Computes 10 specialized intelligence dimensions without subjective human bias:

  • Unit Economics: Exact cost per task, token efficiency, and model pricing breakdown.
  • AI Bill of Materials (AI-BOM): Supply chain mapping of all weights, tools, vector stores, and APIs.
  • Tool Blast Radius: Privilege classification auditing dangerous database/shell write commands.
  • Defensibility & Moat: Proprietary scaffolding complexity vs. commodity prompt wrapper analysis.

4. Decision-Ready Deliverables

Outputs standardized deliverables ready for investment committee review:

  • Investment Committee Deal Memo: Executive Buy / Pass / Conditional verdict with 100-day playbook.
  • CycloneDX 1.6 AI-BOM: Official OWASP JSON standard for software supply chain compliance.
  • Cryptographic Evidence Bundle: Signed manifest.json with bit-level hash verification of all raw and derived records.
  • Audit PDF & Canonical Markdown: Beautiful board-ready presentations backed by verifiable math.
